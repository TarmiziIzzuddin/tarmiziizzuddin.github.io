## Overview

Awarded in 2022, this **TOPDOWN UTeM research grant** totalling **RM 49,430.00** funded the project **"UTeM Smart Aerial Surveillance System: Design and Implementation of Object Identification & Characterization Using Artificial Intelligence Approach"**.

The project designed an AI-driven aerial surveillance system capable of **real-time object identification and characterization** for drone-based monitoring, with applications in campus security, agricultural monitoring, and smart-city infrastructure.

## Project Scope

* **Domain:** Computer vision, aerial robotics, surveillance.
* **Methodologies:** Deep learning, object detection and classification, edge AI deployment.
* **Application:** Drone-based smart aerial surveillance and object identification.
* **Role:** Co-Researcher.
* **Period:** 2022.

## Significance

The TOPDOWN scheme funds high-impact, application-driven research at UTeM. This project demonstrated the feasibility of deploying deep learning models on edge hardware (NVIDIA Jetson-class devices) for real-time surveillance analytics — bridging cutting-edge AI research with practical campus security needs.
